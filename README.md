# Нолики-Крестики
Игра представляет из себя **модифицированную врсию** крестиков ноликов для моего университетского проекта 
* Код для игры будет написан на **Python**
* Игра планируется с возможностью играть с другом на одном экране (**PvP**), или с ИИ (**PvE**). В режиме **PvE** будет **2 уровня** сложности


## Отличия от классической версии
1. Поле не 3x3, а на выбор игрока:
    1. 4x4
    2. 5x5
3. Вместо обычных крестиков и ноликов можно будет использовать встроенные скины, на данный момент планируются следующие вариации:
    1. Классические крестики и нолики
    2. FireFox и Google Chrome
    3. Головы гулей и ведьмака (все из вселеной игр Ведьмак)
    4. Крестики и нолики, но нарисованные как бы карандашом (само поле так же будет нарисованным)
5. после выиграша, победившая сторона как бы поглатит все поле
